# Dotfiles Repository

## Overview

This repository contains my personal dotfiles and system setup scripts for Linux environments. It is designed to automate system configuration and maintain consistency across machines.

---

## Repository Contents

* **homefiles/**
  Contains shell configuration files such as `.bash_aliases` and scripts to apply them.

* **sys-installs/**
  Contains installation scripts for software such as AWS CLI.

* **vim-config/**
  Contains Vim configuration files and setup scripts.

---

## How to Use

### Clone the Repository

```bash
git clone https://github.com/khanhassanhk866/dotfiles.git
cd dotfiles
```

### Run Scripts

Example:

```bash
cd sys-installs
sudo ./install-awscli.sh
```
